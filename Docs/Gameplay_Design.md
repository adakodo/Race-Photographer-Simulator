# Gameplay 流程設計文件

> 本文件定義賽道攝影模擬器的核心遊戲流程與關卡機制。

**相關文件：** [[Photography_Design|攝影系統設計]] · [[Photography_Controls|操作手冊]] · [[BikeAI_MotoGP_Design|BikeAI 設計文件]]

---

## 一、核心 Gameplay Loop

```
進入賽道 → 自由走動 & 拍照（目前無時間限制）
```

玩家扮演賽道攝影師，以**第一人稱**在賽道旁自由移動，透過右鍵切換為**攝影模式**舉起相機拍攝 AI 摩托車賽事照片。

> [!note] 目前狀態
> 倒數與時間限制功能已暫時移除，玩家可自由拍攝不受時間壓力。後期可透過 `LevelConfig` 重新啟用。

---

## 二、遊戲階段

### 2.1 關卡結構

MVP 採用**單一關卡 + 固定條件**，不做關卡選擇 UI。後期可擴充為多關卡線性解鎖或自由模式。

---

### 2.2 關卡開始

| 階段 | 時間 | 畫面 |
|------|------|------|
| 載入 | — | 載入畫面 + 關卡資訊 |
| 開始 | — | 直接進入遊戲，AI 車輛出發，玩家可自由行動 |

> [!note] 倒數功能已暫時移除，後期可透過 `LevelConfig.countdownDuration` 恢復。

---

### 2.3 遊戲進行中

**雙模式操作：**
- **第一人稱模式（預設）**：WASD 移動、Space 跳躍、滑鼠視角，固定 FOV 70°，無景深
- **攝影模式（右鍵切換）**：舉起相機，觀景窗 overlay + HUD 出現，可操作所有相機參數，左鍵拍照
- **圖庫模式（F1）**：遊戲暫停，角色操作全部凍結，瀏覽已拍照片

**操作流程：**
- 右鍵切入攝影模式 → 調整參數 → 左鍵拍照 → 右鍵收起相機繼續移動
- Tab/BackQuote 切換追焦目標（攝影模式下）
- 每張照片即時評分

> [!note] 時間限制目前停用，玩家可自由探索與拍攝。

---

### 2.4 時間結束

| 階段 | 說明 |
|------|------|
| 時間到提示 | 畫面閃爍 / 音效提示「TIME UP」 |
| 緩衝期 | 最後一張照片若正在擷取，等待完成（~1 秒） |
| 進入結算 | 暫停遊戲，切換至結算畫面 |

---

### 2.5 結算畫面

**顯示內容：**

```
┌─────────────────────────────────────────┐
│              RESULTS                     │
│                                          │
│  [照片1]  [照片2]  [照片3]  [照片4] ...  │
│   82pts    67pts    91pts    45pts        │
│                                          │
│  ─────────────────────────────           │
│  最佳照片：91 pts                         │
│  平均分數：71 pts                         │
│  拍攝張數：8                              │
│  有效照片：5（≥60 pts）                   │
│                                          │
│  ★★★  EXCELLENT!                        │
│  目標：3 張 ≥70 pts  ✓ 達成（5張）       │
│                                          │
│  [重玩]  [下一關]  [返回選單]             │
└─────────────────────────────────────────┘
```

**星級評價：**

| 評級 | 條件 |
|------|------|
| ★☆☆ 通過 | 達成最低過關條件（N 張 ≥ X 分） |
| ★★☆ 優秀 | 有效照片數達過關要求的 2 倍，或最高分 ≥ 90 |
| ★★★ 完美 | 有效照片數達過關要求的 3 倍，且最高分 ≥ 90 |
| 失敗 | 未達最低過關條件 |

## 三、過關條件設計

### 3.1 統一條件格式

所有關卡使用同一格式：

> **拍出 N 張 ≥ X 分的照片**

不同關卡透過調整 N（要求張數）和 X（最低分數）控制難度。

| 難度範例 | N | X |
|----------|---|---|
| 教學關 | 1 | 50 |
| 簡單 | 2 | 60 |
| 普通 | 3 | 70 |
| 困難 | 5 | 75 |
| 挑戰 | 3 | 85 |

### 3.2 難度調節手段

除了過關條件，還可透過場景因素調整難度：

| 因素 | 簡單 | 困難 |
|------|------|------|
| 時間 | 180 秒 | 60 秒 |
| 車速 | 慢速練習 | 全速競賽 |
| 車輛數 | 多（容易捕捉） | 少（需要等待） |
| 光線 | 白天、順光 | 陰天、逆光 |
| 賽道 | 直線段多 | 彎道多、遮擋多 |
| 可移動範圍 | 自由 | 限定區域 |

## 四、系統架構

### 4.1 GameManager（關卡流程控制）

遊戲狀態機：

```
Idle → Playing（目前直接進入，無 Countdown / TimeUp）
```

**職責：**
- 持有關卡設定（`LevelConfig` 參照）
- 監聽 `PhotoCaptureManager.OnPhotoReady`，配合 `PhotoScoreEvaluator` 統計照片分數
- 管理遊戲狀態與 UI 切換
- 控制 `PhotoRigController` / `PhotoFreeCam` 的輸入啟用/禁用

> 倒數與計時功能保留在程式碼中（`State.Countdown`、`State.TimeUp`），目前跳過不使用。

### 4.2 LevelConfig（關卡設定資料）

`ScriptableObject`，每關一份：

```
LevelConfig
  ├── levelName: string            （關卡名稱）
  ├── description: string          （關卡描述）
  ├── timeLimit: float             （時間限制，秒）
  ├── requiredCount: int           （需要 N 張）
  ├── requiredScore: float         （每張需 ≥ X 分）
  ├── star2_count: int             （★★ 所需有效張數）
  ├── star2_bestScore: float       （★★ 所需最高分）
  ├── star3_count: int             （★★★ 所需有效張數）
  └── star3_bestScore: float       （★★★ 所需最高分）
```

### 4.3 GameplayHUD（遊戲進行中 UI）

現有 `TrackPhotoHUD` 僅顯示相機參數。`GameplayHUD` 額外顯示：
- 剩餘時間（大字倒數，最後 10 秒閃紅）
- 已拍張數 / 有效張數（≥ X 分）
- 當前最高分
- 關卡目標提示（如「3 張 ≥70 pts」）
- 倒數階段顯示 3-2-1-GO

### 4.4 SettlementUI（結算畫面）

- 全螢幕覆蓋，暫停遊戲
- 展示所有拍攝照片縮圖 + 分數
- 統計資訊（最佳/平均/張數/有效張數）
- 過關判定 + 星級動畫
- 按鈕：重玩（重新載入場景）
