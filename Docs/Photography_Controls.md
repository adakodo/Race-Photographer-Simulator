## 零、操作模式概觀

遊戲有兩個主要操作模式，透過**右鍵**互相切換：

| 模式 | 說明 | 切換方式 |
|------|------|----------|
| **第一人稱模式**（預設） | 自由移動、跳躍，固定 FOV（70°），無景深後處理 | 按右鍵進入攝影模式 |
| **攝影模式** | 舉起相機，觀景窗 overlay + HUD 顯示，可操作所有相機參數，半按對焦 + 放開拍照 | 按右鍵回到第一人稱 |

另外有**圖庫模式**（`Tab` 開啟）：遊戲暫停，角色操作全部停用，僅可瀏覽照片。離開後回到前一個操作模式。

> 兩種操作模式下移動（WASD）和跳躍（Space）皆可使用。

## 二、拍照（半按快門）

攝影模式下使用**左鍵**進行對焦與拍照，模擬真實相機半按快門操作：

| 操作 | 按鍵 | 說明 |
|------|------|------|
| 半按快門（對焦） | 按住左鍵 | 持續 Raycast 畫面中央，鎖定對焦距離 |
| 拍照 | 放開左鍵 | 觸發快門，擷取當前畫面 |

> 對焦使用畫面中央 Raycast，命中 `FocusTarget` 層的物件會有較大碰撞判定範圍。觀景窗中央對焦框會顯示合焦狀態：綠色 = 合焦、紅色 = 未合焦。

## 三、相機參數調整（攝影模式限定）

| 操作 | 按鍵 | 步進 | 說明 |
|------|------|------|------|
| 快門速度 ↓（更慢） | `1` | 1/3 EV | 快門變慢，進光更多 |
| 快門速度 ↑（更快） | `2` | 1/3 EV | 快門變快，凝結動態 |
| 光圈 ↓（更大/淺景深） | `3` | 1/3 EV | F 值變小，背景更糊 |
| 光圈 ↑（更小/深景深） | `4` | 1/3 EV | F 值變大，全面清晰 |
| 曝光補償 ↓（更暗） | `Q` | 0.3 EV | 整體畫面變暗 |
| 曝光補償 ↑（更亮） | `E` | 0.3 EV | 整體畫面變亮 |
| 切換鏡頭 A（24-70mm） | `F1` | — | 廣角鏡頭 |
| 切換鏡頭 B（100-400mm） | `F2` | — | 望遠鏡頭 |
| 變焦（焦距調整） | 滾輪 | 5mm | 改變視角寬窄 |

### 曝光模式

- **快門優先（預設）**：使用者設定快門速度，系統自動計算 ISO 補償曝光

## 四、參數效果說明

> [!tip] 核心概念
> 每個參數都同時影響「畫面視覺效果」和「照片評分」。理解這些關係是拍出高分照片的關鍵。

### 4.1 快門速度（Shutter Speed）

| 影響面向 | 說明 |
|----------|------|
| **畫面效果** | 快門越慢 → 動態模糊（Motion Blur）越明顯；快門越快 → 動作凝結、畫面銳利 |
| **評分：銳利度** | 安全快門規則 = 1/焦距。例如用 200mm 鏡頭時，快門需 ≥ 1/200s 才不會因手震模糊 |
| **評分：搖攝補償** | 若成功追焦（主體清晰、背景模糊），慢快門反而能獲得額外加分 |

**賽道攝影建議**：使用 1/250s~1/500s 凝結車輛，或刻意用 1/60s~1/125s 搖攝製造背景流動感。

### 4.2 光圈（Aperture）

| 影響面向 | 說明 |
|----------|------|
| **畫面效果** | 光圈越大（F 值越小）→ 景深越淺（背景散景越明顯）；光圈越小 → 全畫面清晰 |
| **評分：對焦** | 淺景深時合焦容錯更小，對焦必須精準才能得高分 |
| **曝光連動** | 光圈越大 → 進光越多 → Auto ISO 會降低 ISO 保持曝光平衡 |

**賽道攝影建議**：f/2.8~f/4 可獲得漂亮的背景虛化，突出車輛主體。

### 4.3 曝光補償（Exposure Compensation）

| 影響面向 | 說明 |
|----------|------|
| **畫面效果** | 正值 → 畫面整體變亮；負值 → 畫面整體變暗 |
| **評分：曝光** | 偏離 ±0 越多，曝光分數越低。理想值為 ±0（正確曝光） |

**賽道攝影建議**：通常保持 ±0，逆光時可 +0.3~+0.6 補償。

### 4.4 焦距（Focal Length）

| 影響面向 | 說明 |
|----------|------|
| **畫面效果** | 焦距越長 → 視角越窄（望遠壓縮感）；焦距越短 → 視角越廣（空間感） |
| **評分：構圖** | 影響主體在畫面中的大小佔比，適當填滿畫面有助構圖分數 |
| **評分：銳利度** | 焦距越長，安全快門要求越高（200mm 需 1/200s 以上） |
| **手震影響** | 焦距越長，手持晃動的影響越被放大 |

**賽道攝影建議**：100-400mm 望遠鏡頭適合在賽道旁拍攝，可以在安全距離外拍到車輛特寫。

### 4.5 評分維度總覽

| 維度 | 權重 | 主要影響參數 | 得分關鍵 |
|------|------|-------------|---------|
| **構圖** | 30% | 焦距、拍攝角度 | 主體接近三分點位置，不被裁切 |
| **曝光** | 25% | 曝光補償、ISO | 曝光補償接近 ±0，ISO 不過高 |
| **銳利度** | 25% | 快門速度、焦距 | 快門 ≥ 1/焦距（安全快門） |
| **對焦** | 20% | 光圈、對焦操作 | 主體在景深範圍內（合焦） |

> [!important] 拍到車才有分
> 照片中必須有摩托車出現才會計算分數。系統自動偵測畫面中最接近中央的車輛作為評分主體。

## 五、照片圖庫

| 操作 | 按鍵 | 說明 |
|------|------|------|
| 開/關圖庫 | `Tab` | 暫停遊戲，角色操作全部停用，顯示滑鼠游標 |

## 六、畫面提示

### 操作提示（第一人稱模式）

遊戲開始後左下角顯示操作提示，12 秒後自動淡出。按 `F3` 可手動顯示/隱藏。

### 觀景窗 Overlay（攝影模式）

由 `ViewfinderOverlay` 繪製，僅在攝影模式顯示：

| 元素 | 說明 |
|------|------|
| 三分線 | 構圖輔助九宮格 |
| 中心十字 | 畫面中央標記 |
| 水平線 | 畫面水平中線 |
| 安全框 | 2.39:1 寬銀幕構圖框 |
| 對焦框 | 中央四角方括號，合焦綠色 / 未合焦紅色 + 對焦距離 |
| 反光鏡遮黑 | 快門觸發瞬間畫面變黑 |

### HUD 狀態列（攝影模式）

畫面底部黑色半透明條，三層顯示：

```
  快門速度      光圈         曝光補償     焦距        ← 標籤（灰）
[ 1/500        f/2.8        +0.0        200mm ]    ← 數值（白）
  1 / 2        3 / 4        Q / E       Scroll     ← 操作按鍵（黃）
```

### 攝影模式操作提示（右下角）

攝影模式下右下角常駐小提示：

```
按住左鍵  對焦
放開左鍵  拍照
F1 / F2   切換鏡頭
右鍵      收起相機
```

## 七、擷取管線流程

```
1. 攝影模式下按住左鍵對焦 → 放開左鍵拍照
2. TrackPhotoRig 觸發 OnShutter 事件
3. PhotoCaptureManager 排程 CopyColorAfterPost（實例方法）
4. 下一幀：CustomPass blit 後處理結果 → RTHandle
5. AsyncGPUReadback 讀回 CPU
6. 生成 Texture2D
7. PhotoGallery 儲存照片副本 + PhotoScoreEvaluator 計算評分
8. PhotoPreviewHUD 在左下角顯示縮圖預覽（3 秒後淡出）
```

## 九、鏡頭規格

| 鏡頭 | 焦段 | 最大光圈 | 適用場景 |
|------|------|---------|---------|
| A (24-70mm) | 24mm ~ 70mm | f/2.8 ~ f/4.0 | 近距離、環境、全景 |
| B (100-400mm) | 100mm ~ 400mm | f/4.5 ~ f/6.3 | 遠距離追焦、車輛特寫 |

> 切換鏡頭會重置為該鏡頭預設焦距。變焦鏡頭在望遠端光圈會自動縮小。
