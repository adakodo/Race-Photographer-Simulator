## 二、鏡頭操作

| 操作 | 按鍵 | 說明 |
|------|------|------|
| 切換鏡頭 A（24-70mm） | `1` | 切換後重置為該鏡頭預設焦距 |
| 切換鏡頭 B（100-400mm） | `2` | 切換後重置為該鏡頭預設焦距 |
| 變焦（拉近） | 滾輪向下 | 焦距增加 |
| 變焦（拉遠） | 滾輪向上 | 焦距減少 |

### 鏡頭規格

| 鏡頭 | 焦段 | 最大光圈 | 變焦步進 |
|------|------|---------|---------|
| A (24-70) | 24mm ~ 70mm | f/2.8（廣角端）~ f/4.0（望遠端） | 2mm |
| B (100-400) | 100mm ~ 400mm | f/4.5（廣角端）~ f/6.3（望遠端） | 5mm |

## 三、曝光控制

| 操作 | 按鍵 | 步進 | 範圍 |
|------|------|------|------|
| 快門速度 ↓（更慢） | `[` | 1/3 EV | 1/8000s ~ 30s |
| 快門速度 ↑（更快） | `]` | 1/3 EV | 1/8000s ~ 30s |
| 光圈 ↓（更大/更淺景深） | `'` | 1/3 EV | f/0.7 ~ f/32 |
| 光圈 ↑（更小/更深景深） | `;` | 1/3 EV | f/0.7 ~ f/32 |
| ISO ↓ | `-` | 1/3 EV | 100 ~ 6400 |
| ISO ↑ | `=` | 1/3 EV | 100 ~ 6400 |
| 曝光補償 ↓ | `,` | 0.3 EV | 無限制 |
| 曝光補償 ↑ | `.` | 0.3 EV | 無限制 |
| ND 濾鏡 ↓（減少減光） | `N` | 0.3 stops | 0 ~ 8 stops |
| ND 濾鏡 ↑（增加減光） | `M` | 0.3 stops | 0 ~ 8 stops |

### 曝光模式

- **快門優先（預設）**：使用者設定快門速度，系統自動計算 ISO
- **手動 ISO**：按 ISO 按鍵後自動切換為手動模式

### ISO 標準值表

100 → 125 → 160 → 200 → 250 → 320 → 400 → 500 → 640 → 800 → 1000 → 1250 → 1600 → 2000 → 2500 → 3200 → 4000 → 5000 → 6400

## 四、對焦

| 操作 | 按鍵 | 說明 |
|------|------|------|
| AF-C 開/關 | `R` | 切換自動連續對焦 |
| 手動對焦（近） | `F`（按住） | 對焦距離縮短 |
| 手動對焦（遠） | `G`（按住） | 對焦距離增加 |
| 中央點對焦 | 滑鼠中鍵 | Raycast 螢幕中央，對焦至命中點 |
| 點擊對焦 | `Alt` + 左鍵 | Raycast 點擊位置，對焦至命中點 |

### AF-C 行為

- 持續追蹤 `subject`（追焦目標）的距離
- 使用速度預測（`afLeadSec`）補償追焦延遲
- 可設定對焦範圍限制（預設 0.5m ~ 500m）
- 手動對焦操作會自動關閉 AF-C

## 五、快門與連拍

| 操作 | 按鍵 | 說明 |
|------|------|------|
| 單張拍攝 | `Enter` | 不受連拍模式影響 |
| 連拍開始/停止 | `Space` | 切換按住快門狀態 |
| 切換驅動模式 | `V` | 循環：Single → Low → High → Custom |

### 驅動模式

| 模式 | 連拍速度 | 說明 |
|------|---------|------|
| Single | — | 僅單張，按 Enter 觸發 |
| ContinuousLow | 5 fps | 低速連拍 |
| ContinuousHigh | 15 fps | 高速連拍 |
| Custom | 8 fps（可調） | 自訂連拍速度 |

> 每次快門觸發後會有反光鏡遮黑效果（預設 0.05 秒），模擬 DSLR 觀景窗暫時變黑。

## 七、觀景窗 Overlay

由獨立組件 `ViewfinderOverlay` 負責繪製，掛在與 `TrackPhotoRig` 同一 GameObject 上。預設全部開啟，可在 Inspector 中個別關閉：

| 元素 | 說明 |
|------|------|
| 三分線 | 構圖輔助九宮格 |
| 中心十字 | 畫面中央標記 |
| 水平線 | 畫面水平中線 |
| 安全框 | 指定比例的安全構圖框（預設 2.39:1 寬銀幕） |
| 對焦框 | 中央四角方括號，合焦時綠色、未合焦時紅色；框下顯示對焦距離 |
| 反光鏡遮黑 | 快門觸發瞬間畫面變黑 |

## 九、擷取管線流程

```
1. 按下快門（Enter / Space 連拍）
2. TrackPhotoRig 觸發 OnShutter 事件
3. PhotoCaptureManager 排程 CopyColorAfterPost（實例方法）
4. 下一幀：CustomPass blit 後處理結果 → RTHandle
5. AsyncGPUReadback 讀回 CPU
6. 生成 Texture2D
7. PhotoPrintSpawner 在世界空間生成照片 Quad
8. PhotoGallery 儲存照片副本 + PhotoScoreEvaluator 計算評分
```

> 連拍過程中由反光鏡遮黑間隔（blackoutSec）自然限制擷取頻率。
